# NutriSync UI Specification

## 1. Product UI Vision

NutriSync is an AI-powered personalized nutrition decision assistant.

### Core Product Message

> Don't just track what you eat. Know what to do next.

The UI must make this message obvious within the first few seconds of using the application.

NutriSync should feel:

- Intelligent
- Personalized
- Trustworthy
- Modern
- Simple
- Student-friendly
- Action-oriented

It should NOT feel like:

- A medical dashboard
- A generic calorie tracker
- A collection of unrelated AI demos
- A futuristic health experiment
- An overloaded analytics dashboard

---

# 2. PRIMARY TARGET USERS

NutriSync is primarily designed for:

- College students
- Hostel students
- Young professionals

Typical food environments:

- Hostel/mess food
- College canteen
- Home food
- Restaurants
- Food delivery
- Irregular meal schedules
- Limited budgets

The interface should prioritize quick decisions rather than complicated nutrition analysis.
